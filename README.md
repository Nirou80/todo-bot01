# 🤖 Todo List Telegram Bot

یک ربات تلگرامی کاربردی برای مدیریت کارهای روزمره (Todo List) که با زبان پایتون و دیتابیس SQLite پیاده‌سازی شده است.

## 🌟 قابلیت‌ها
- ➕ افزودن کار جدید (/add)
- 📋 دریافت لیست کامل کارهای ثبت‌شده (/list)
- ✅ علامت‌زدن کارها به عنوان انجام‌شده (/done)
- 💾 ذخیره‌سازی دائمی اطلاعات در دیتابیس SQLite

## 🛠 پیش‌نیازها و تکنولوژی‌ها
- Python 3.10+
- python-telegram-bot
- python-dotenv
- SQLite3
